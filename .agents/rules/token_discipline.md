# Quy Tắc Tiết Kiệm Token & Thao Tác (Token & Workflow Discipline)

1. **Tác động đúng file đích:** Chỉ đọc và thao tác trực tiếp vào đúng file đích cần sửa, KHÔNG đọc hay grep dàn trải toàn dự án khi không có yêu cầu.
2. **Không tự ý chạy browser agent:** TUYỆT ĐỐI KHÔNG tự ý khởi chạy browser agent hay các quy trình kiểm tra rườm rà làm phình token.
3. **Phản hồi đúng trọng tâm:** Luôn phản hồi ngắn gọn, súc tích và đúng trọng tâm yêu cầu của người dùng.
